# Student Registration System

A responsive student registration form built with HTML, CSS, and JavaScript — featuring real-time validation, a password strength indicator, and a light/dark mode toggle.

## Features

- **Personal information form** — full name, email, username, phone number, date of birth, and gender fields
- **Password handling**
  - Show/hide password toggle
  - Live password strength indicator as the user types
  - Confirm password field with match validation
- **Light / Dark mode toggle** — switches the entire interface theme instantly
- **Form validation** — checks required fields and formatting before submission
- **Responsive layout** — adapts cleanly to different screen sizes

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## What I Learned

Building this project helped me practice:
- Structuring a multi-field form with clear grouping and labels
- Writing JavaScript for real-time input feedback (password strength, show/hide toggle)
- Implementing a theme toggle using JavaScript and CSS custom properties
- Basic client-side form validation
